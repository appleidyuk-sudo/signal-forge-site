Add Symbol

Adding a New Position

Tap the + button on the Positions screen. You can:

  1. Type a symbol manually — enter the ticker and set a portfolio weight (5%–100% in 5% steps)
  2. Pick from IV Suggestions — the built-in IV Scanner shows high-IV candidates ranked by premium yield (see IV Scanner section)
  3. Tap Add — the position is created, price is fetched, and the first wheel cycle runs automatically
How weights work: Portfolio weight determines how much capital is allocated to each symbol for position sizing. Weights auto-normalize to sum to 100%. A 20% weight on a $100K account means up to $20K in buying power for that symbol's puts.

Under the Hood

How the Scanner Works

// For each symbol in the universe:
1. Fetch stock price from Yahoo Finance
2. Fetch option chain (nearest monthly expiration)
3. Find ATM put (closest strike to current price)
4. Extract IV from ATM put

// Calculate estimated metrics:
premium_30d = IV × √(30/365) × price × 0.4
annualized_yield = (premium / price) × (365 / DTE)
iv_rank = percentile within scanned universe
Strategy tip: Look for stocks with IV Rank above 0.5 and Yield above 15%. These are the sweet spots where premium income justifies the assignment risk.

Methodology

How the Backtest Engine Works

The engine replays history day-by-day, simulating the exact same logic as live execution:

  1. Mark daily snapshot (NLV, cash, stock value, premium)
  2. Check active option: if DTE = 0, handle expiration/assignment/call-away
  3. Check roll eligibility: if P&L target hit or DTE trigger, roll
  4. Write new option if none active: calculate strike + premium via Black-Scholes
// Historical Volatility for pricing:
daily_returns = log(price[t] / price[t-1])
annual_vol = stdev(daily_returns) × √252

// Black-Scholes for option pricing (when chain unavailable):
d1 = [log(S/K) + (r + σ²/2)T] / (σ√T)
d2 = d1 - σ√T
Note: Backtests use historical volatility rather than real-time IV, and assume perfect fills. Actual results will vary due to slippage, bid-ask spreads, and IV changes.

🚀 GETTING STARTED
Quick Start

Your First Wheel in 5 Steps

  1. Configure your account — Go to Settings, set your starting cash and margin preferences
  2. Scan for candidates — Go to Positions → tap + → browse IV Suggestions. Look for stocks with high yield and IV rank above 0.5
  3. Add 3-5 symbols — Start small. Set equal weights (20% each). The engine will allocate capital accordingly.
  4. Run your first cycle — Tap the manual execute button (↻) on the Dashboard. The engine will write puts on each position.
  5. Monitor & learn — Watch the phases progress. Check the Dashboard daily. When positions roll or get assigned, the engine handles it automatically.
Beginner tip: Start with a 0.25 delta (safer) and well-known stocks like AAPL or SPY. As you get comfortable with the wheel mechanics, you can increase delta for more premium or add higher-IV names.
Workflow

Recommended Daily Routine

  1. Morning: Open Dashboard → check overnight wheel status and recent trades
  2. Review: Check any positions with DTE < 15 (yellow/red badges) — these are approaching roll territory
  3. Scan: Weekly, check the IV Scanner for new high-yield candidates
  4. Backtest: Before adding a new symbol, run a 1-year backtest to see historical wheel performance
  5. Adjust: If auto-execute is off, manually run a cycle when you see favorable conditions
