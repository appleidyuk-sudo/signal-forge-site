Step 3

Composite Score

score = 0.35 × signal + 0.25 × trend + 0.20 × momentum + 0.10 × risk + 0.10 × sentiment

Result is a single number from 0 to 100.

Step 4

Threshold Check

The composite score is compared against user-adjustable thresholds (configurable in Settings).

≤ 35 → SELL HOLD ≥ 65 → BUY
0 35 65 100
// Read from Settings (adjustable via sliders)
let buyThreshold = 65 // default
let sellThreshold = 35 // default

if score >= buyThreshold → BUY // opens position if none open
if score <= sellThreshold → SELL // closes any open buys
else → HOLD // no action
Threshold impact: Tighter thresholds (55/45) → more trades, more signals, more noise. Wider thresholds (75/25) → fewer trades, higher conviction, more missed moves. The default 65/35 gives a 30-point Hold zone, which is a moderate stance.
